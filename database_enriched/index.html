How to wire reminders (2-minute integration)

// 1) Resolve engine_code for user vehicle SELECT engine_code FROM vehicle_variants WHERE car_brand=:b AND car_model=:m AND car_year=:y LIMIT 1; // 2) Get intervals SELECT oil_change_interval_km, oil_change_interval_months, timing_type, timing_belt_interval_km FROM engine_service_specs WHERE engine_code=:code; // 3) Compute due — whichever hits first (km or time) dueKm = lastKm + intervalKm - currentKm dueDays = (lastDate + intervalMonths*30.44d) - today overdue = dueKm<=0 || dueDays<=0; dueSoon = dueKm<=1000 || dueDays<=30 // Chain? hide belt, show inspection: timing_chain_inspection_km // Wet belt? warn oil-immersed dealer procedure
